Ручная проверка сценариев по коду:

- Первый запуск без `settings.json`: `AppSettings.Current` остаётся с безопасными значениями по умолчанию; запись выполняется при изменении настройки.
- Повреждённый `settings.json`: ошибка чтения/JSON ловится, файл best-effort копируется в `.bad`, используются значения по умолчанию. При запрете записи приложение продолжает с настройками по умолчанию.
- Повреждённый `measurements.json`: `MeasurementStore.Read()` возвращает пустой список при JSON/IO/ACL ошибке; запись атомарная через `.tmp`, ошибка возвращает `false`.
- Повреждённый `journal.json`: при наличии корректного `.bak` загрузка восстанавливается; если обе копии непригодны, журнал становится недоступен и новые изменения блокируются. Без прав запись машинного журнала запрещена.
- Нет прав на запись в `%LOCALAPPDATA%`: `TryEnsureDir`/сохранение настроек не выбрасывают ошибку наружу; UI продолжает работу, сохранение best-effort и предупреждается в логе. Этот ACL-сценарий не воспроизводился изменением прав на профиле владельца.
- Очень длинные пути: манифест содержит `longPathAware=true`; основные файловые операции имеют обработку `PathTooLongException` либо общий безопасный перехват ошибок. Физический длинный путь не создавался.
- Английская Windows: выбор автоязыка опирается на `CultureInfo.CurrentUICulture`; `--lang en` прогнал английскую локализацию на текущей Windows, но ОС с английским системным языком отдельно не запускалась.
- Два экземпляра: штатный запуск использует `Local\Lycoris.SingleInstance`, атомарное получение mutex и активацию существующего окна; snapshot/selftest намеренно обходят mutex, поэтому одновременный запуск двух обычных окон не проверялся экспериментально.
