# Подпись Lycoris.exe: что выбрать владельцу (05.11.2026)

Зачем: без подписи Windows SmartScreen показывает «Windows защитила ваш компьютер · неизвестный издатель», антивирусы чаще
ошибаются. Подпись показывает ваше имя издателя. Технически всё готово: `tools\sign.ps1` подписывает exe, `tools\release.ps1`
вызывает подпись при выпуске (docs/signing.md). Не хватает только сертификата — его выдают на вашу личность, купить или получить
его за вас нельзя.

Источник сравнения: Microsoft Learn — «Code signing options for Windows app developers», «SmartScreen reputation for Windows app
developers», «Free developer registration for individual developers» (проверено 05.11.2026).

| Вариант | Цена | Доступность для частного лица | SmartScreen |
|---|---|---|---|
| Azure Artifact Signing (бывш. Trusted Signing) | ≈ $9,99/мес | только США и Канада | предупреждение, пока не наберётся репутация |
| OV-сертификат (Sectigo, Certum, DigiCert, GlobalSign) | ≈ $150–300/год | весь мир; ключ на USB-токене или в облачном HSM | то же, что выше |
| EV-сертификат | $400+/год | весь мир | с 2024 г. то же, что OV — переплачивать не нужно |
| Microsoft Store (пакет MSIX) | бесплатно | почти 200 стран; паспорт + селфи | без предупреждений |
| Самоподписанный | бесплатно | — | как без подписи (только для своего ПК) |

Важно: ни один платный сертификат не убирает предупреждение сразу — репутация копится неделями и сотнями чистых установок;
подписывать все выпуски одним и тем же именем, чтобы она не начиналась с нуля.

## Рекомендация

1. **Вы в США или Канаде** → Azure Artifact Signing: дешевле всего, без токена, подписывает прямо из `release.ps1`.
2. **Иначе** → OV-сертификат для частного лица (Individual / «Индивидуальный разработчик»). Порядок:
   1) выбрать удостоверяющий центр, который выдаёт сертификаты частным лицам в вашей стране и принимает доступную вам оплату;
   2) пройти проверку личности (паспорт, иногда видеозвонок; несколько рабочих дней);
   3) получить токен или облачный ключ; вставить токен в этот ПК;
   4) сказать Claude «сертификат готов» — он настроит `tools\sign.ps1` на ваш сертификат (отпечаток), подпишет текущий выпуск
      и проверит, что `Get-AuthenticodeSignature` показывает «Valid» и ваше имя. Пароль/PIN токена вводите только вы.
3. **Бесплатный путь — Microsoft Store**: регистрация на https://storedeveloper.microsoft.com (бесплатно для частных лиц).
   Ограничение: программе с правами администратора нужен restricted capability `allowElevation`, Microsoft одобряет его «по строгим
   критериям» (письмо с обоснованием на reportapp@microsoft.com), а Lycoris нужно упаковать в MSIX и проверить, что журнал отката,
   службы и реестр работают внутри пакета. Это отдельный проект на несколько дней с неизвестным исходом одобрения.
