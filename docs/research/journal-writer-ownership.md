# Владение машинным журналом

Журнал Lycoris в ProgramData обслуживает установку целиком. Именованный мьютекс окна действует в пределах сеанса Windows. Пользователь другого сеанса может читать журнал без захвата права записи.

Прежний старт CLI загружал состояние до проверки блокировки. При выходе любого повышенного процесса вызывался Save, включая пробный запуск и отказ из-за открытого экземпляра. Загрузка журнала могла также копировать повреждённый файл. Это позволяло наблюдателю затереть новое состояние или изменить файлы во время работы другого процесса.

Обычное повышенное окно, применение сценария и разрешённый E2E удерживают один глобальный мьютекс до завершения работы с журналом. Мьютекс создаётся с защищённым ACL для Administrators и SYSTEM. Перед захватом проверяются владелец и ACL действительного объекта. Это происходит до миграции и исправления прав ProgramData, чтобы один процесс мог выполнить их и обработать недоверенный журнал. Мьютекс DEBUG привязан к отдельному тестовому корню. [Пространства имён объектов Windows](https://learn.microsoft.com/en-us/windows/win32/termserv/kernel-object-namespaces) · [.NET MutexAcl](https://learn.microsoft.com/en-us/dotnet/api/system.threading.mutexacl.create?view=net-10.0)

Журнал связывает право записи с тем экземпляром владения, при котором он был прочитан. Пробный CLI и вспомогательные режимы читают данные без восстановления и сохранения журнала при выходе. Повышенный наблюдатель сохраняет право восстановить временное ограничение частоты точки восстановления, если его изменил сам этот процесс.

Проверка Windows API в PowerShell на .NET 10.0.14 с временным глобальным именем и ACL текущего пользователя подтвердила сохранение владельца и признаков DiscretionaryAclPresent и DiscretionaryAclProtected при чтении фактического объекта. Установка и машинный журнал в этой проверке не использовались. Проверка настоящего ACL Administrators и SYSTEM входит в тест одноразовой повышенной Windows-среды.

Процессы прежних версий не знают о новом мьютексе. При переходе между версиями нужно закрыть старые копии Lycoris, включая копии в других сеансах Windows.
