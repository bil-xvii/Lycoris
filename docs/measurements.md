# Замеры до и после

Lycoris сохраняет замер только после нажатия пользователем кнопки на странице «Главная». Сбор не запускается в фоне, данные читаются локально и никуда не отправляются.

Записываются версия и сборка Windows, версия Lycoris, число включённых элементов автозапуска, свободная память и время последней загрузки Windows из журнала Diagnostics-Performance (если источник недоступен, указывается «недоступно»). Условия сравниваются; при различиях результат помечается «несопоставимо». Повторные замеры показывают разброс и не обещают прирост производительности.

Файл хранится в `%LOCALAPPDATA%\Lycoris\measurements.json`. Чтобы удалить историю, закройте Lycoris и удалите этот файл.
