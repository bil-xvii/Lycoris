# Макеты развития продукта

## Как смотреть

Откройте PNG для быстрого просмотра или HTML в Edge/другом браузере. Каждый HTML — самостоятельный макет на 1380×880; кнопки показаны как элементы интерфейса и не выполняют действий. Файлы PNG отрендерены headless Edge в размере 1380×880.

## Варианты главного экрана

- **A — Быстрый старт:** большая кнопка проверки и три прямых вопроса; понятен новичку, но несколько крупных входов могут конкурировать за внимание.
- **B — Карточки целей:** выбираешь задачу, сразу видны безопасные маршруты; легко сканировать, но карточки требуют больше места и содержат меньше текущей диагностики.
- **C — Лента Доктора:** результаты диагностики и исправления рядом; объясняет состояние ПК, но может перегрузить новичка показателями.

## Остальные экраны

- `first-run.html` — мастер первого запуска, три шага видны в одном макете.
- `expert.html` — режим «Простой / Эксперт», список автозапуска и предпросмотр изменения. Команды остаются подписанными.
- `before-after.html` — честное сравнение с источниками и оговоркой о сопоставимости.
