# Критика задания мастера первого запуска
1. Закрытие окна посреди шага должно сохранять выбор и продолжать мастер при следующем запуске.
2. Для настольного ПК без батареи карточка ноутбука не должна отображаться даже при неизвестном профиле.
3. При отсутствии сети мастер обязан работать полностью офлайн и не блокировать переходы.
4. Без прав администратора мастер остаётся доступен в режиме просмотра и объясняет ограничения.
5. Английская локализация должна покрывать тексты, кнопки и длинные подписи без обрезки.
6. Компактное окно 1120×720 требует проверки прокрутки и доступности всех кнопок.
7. Повторный запуск из настроек и палитры должен открывать мастер без потери существующих настроек.
8. Старым пользователям с журналом, экспертным режимом или LastProfile нужен мягкий вход, а не автопоказ.
9. Сценарии снимка, selftest и replay-intent не должны запускать мастер без явного demo-флага.
10. Смена языка/закрытие во время мастера и отсутствие выбранной цели не должны сбрасывать валидные настройки.
