# Lycoris: спокойный профессиональный интерфейс

Задача владельца, 19.11.2026: полностью обновить дизайн, сделать его профессиональным, современным и визуально богатым, с приятными приглушёнными цветами.

## Решение до реализации

Существующие Theme/Colors, Typography и Controls уже объединяют все страницы. Используем их, сохраняем команды, защиту действий, локализацию и навигацию. Отдельно меняем композицию shell и Dashboard, чтобы результат был полноценным изменением интерфейса.

- Основа: глубокий графит `#12171E`, панель `#19212B`, приподнятая поверхность `#202A36`, граница `#415063`, основной текст `#E8EDF2`, акцент мягкой стали `#ABC0D4`. Значения уточняются проверкой контраста.
- Шрифт: Segoe UI Variable с системным Segoe UI fallback, поддерживающий русский; спокойные заголовки Semibold, пропорциональные показатели. Mono только для путей, идентификаторов и журналов.
- Навигация: отдельная визуально спокойная колонка, ясное активное состояние, подписи и знакомые Fluent icons, умеренные интервалы.
- Панель: компактная сводка состояния, выделенное основное действие игрового сеанса, вторичные инструменты и читаемый список советов. Карточки разного назначения не должны выглядеть шестью равнозначными кнопками.
- Управление: единые кнопки, фильтры, вкладки, поля ввода и закреплённые панели; явно видимые hover, focus, selected и disabled. Контраст текста не ниже 4.5:1, информативных границ и индикаторов не ниже 3:1. Красный применяется к риску, ошибки не скрываются.
- Убираем декоративную штриховку и избыток заглавных надписей. Не добавляем фоновые анимации, зависимости, удалённые шрифты или изображения.

Самопроверка направления: дорогой вид создаётся точной типографикой, ритмом и материалами поверхностей. Не добавляем золотые украшения, стеклянные градиенты или одинаковые огромные карточки.

## Категории навигации

Дополнение владельца 19.11.2026: панели и иконки заново распределяются от главной до восстановления.

| Категория | Разделы по порядку |
| --- | --- |
| Главное | Главная, Панель, Помощник |
| Игры и производительность | Игры, Оптимизация |
| Программы | Приложения, Удаление и отключение |
| Windows и устройства | Автозапуск и службы, Устройства и сеть, Драйверы, Обслуживание |
| Восстановление | Восстановление |

Настройки закреплены внизу. Меняется только представление навигации: сортировка NavPages отдельно от Pages, прежние идентификаторы, экземпляры страниц, команды и ограничения доступа сохраняются. На маленьком окне список прокручивается; групповые интервалы остаются компактными.

## Приёмка

1. Debug и Release сборки: 0 ошибок, 0 предупреждений.
2. Контраст и локализация: целевые тесты проходят; изменения строк имеют английские переводы.
3. Полный набор тестов проходит с отдельно отмеченными opt-in пропусками.
4. RU/EN selftest: нет ошибок привязки и необработанных исключений.
5. Просмотр настоящих PNG: shell, главная, панель, игры, оптимизация, приложения, удаление, помощник, настройки и диалоги. Дополнительно узкое окно 1120×720.
6. Проверки работают в изолированном DEBUG LYCORIS_TEST_ROOT, с заблокированными системными изменениями. Снимки реального ПК не публикуются без очистки личных данных.
7. Перед установкой или публикацией — независимый release gate по финальному diff и фактическим результатам.
