Вариант A — «Главный экран с быстрыми действиями»

Идея: Панель становится стартовой площадкой. Сверху — одна строка с оценкой, под ней шесть крупных плиток-ярлыков с текущим значением и кнопкой: игровой сеанс, оптимизация, очистка, драйвер видеокарты, откат, пинг. Ниже — список проблем с кнопками-действиями (глагол, а не «куда перейти»). Мониторинг сжат в четыре строки справа. Каждая остальная страница получает одинаковое строение: заголовок с ОДНОЙ главной кнопкой, вкладки в рамке, список, липкая панель внизу.

Что видно на макетах: кадр 1 — новая Панель; кадр 2 — Оптимизация по той же «анатомии» (главная кнопка в заголовке, «ПРИМЕНИТЬ» на каждом тайле профиля, «сейчас → станет» виден без раскрытия). Общие исправления (поиск кнопкой, «ОТКАТ · 71» с рамкой, подписи у иконок, бейджи в меню, контраст) включены.
