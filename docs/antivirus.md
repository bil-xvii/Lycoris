# Антивирусы и SmartScreen: почему MONOLITH может «ругаться» и что с этим делать

Владелец: «чтобы при скачивании не выскакивало как программа для вирусов». Честный итог в двух строках:
**часть работы сделана в коде (ниже), но полностью убрать предупреждения может только репутация файла — подпись, отправка на проверку
и время/число скачиваний.** Обещать «ноль срабатываний» нельзя ни одной программе, которая меняет настройки Windows.

## 1. Почему оптимизатор Windows выглядит подозрительно

Антивирусы оценивают не намерения, а поведение и «упакованность». У MONOLITH совпадают с «вредоносными» признаками:

| Что видит антивирус | Откуда это в MONOLITH | Можно ли убрать |
|---|---|---|
| Файл без цифровой подписи, мало скачиваний (SmartScreen: «Windows защитила ваш компьютер») | любой новый неподписанный exe | только подпись + репутация (раздел 3) |
| Большой «упакованный» файл: сжатый пакет внутри exe | однофайловая публикация со сжатием (`EnableCompressionInSingleFile`) | не убрано сознательно — см. раздел 2 |
| При первом запуске распаковываются нативные библиотеки WPF в `%TEMP%\.net\…` | `IncludeNativeLibrariesForSelfExtract` — без этого WPF-приложение не будет одним файлом | нет, пока нужен один exe |
| Запуск PowerShell с `-ExecutionPolicy Bypass -EncodedCommand` | `ProcessRunner.RunPowerShellAsync`, команды отката в журнале, часть твиков | **нет — это основа безопасного отката**; в журнале приложения каждая такая команда записана читаемым текстом (`powershell: <название> (<значение>)`) |
| Изменение реестра, служб, планов питания, задач | весь смысл оптимизатора; всё идёт через `ChangeSession` с журналом отката и точкой восстановления | нет; документировано в `CLAUDE.md` и «Настройки → Как MONOLITH защищает систему» |
| Чтение/отключение записей автозапуска (`…\CurrentVersion\Run`) | страница «Автозапуск и службы». MONOLITH **сам себя в автозапуск не прописывает** | нет, это функция |
| Запрос прав администратора, перезапуск самого себя | `Elevation.TryRelaunchElevated` (UAC, `runas`), по умолчанию приложение открывается **без** UAC (`asInvoker`) | нет |
| Завершение процессов, снижение приоритета, очистка списка ожидания памяти (`NtSetSystemInformation`), `SeProfileSingleProcessPrivilege` | игровой режим («Игры») — только по кнопке, всё возвращается в исходное состояние | нет |
| Скрытое окно у дочерних процессов (`CreateNoWindow`) | служебные утилиты `sfc`, `dism`, `pnputil`… — вывод показывается в журнале | нет, но все они из `System32` по полному пути |
| Самообновление: скачивание exe и замена файла | `Core/Updates` (адрес только `github.com/bil-xvii/MONOLITH-releases`, SHA-256, подпись, откат) | нет — это функция; поведение прозрачно описано в `docs/releasing.md` |
| Сетевые запросы | проверка обновлений (api.github.com), каталог драйверов/установщиков производителей, пинг/DNS-тест — только по действию пользователя; **ничего о ПК наружу не отправляется** | нет |

Что **не** делает MONOLITH (поэтому ложные срабатывания — именно ложные): не отключает Защитник/брандмауэр/UAC/SmartScreen,
не прописывает себя в автозапуск, не скрывает окно, не внедряется в чужие процессы, не шифрует и не удаляет пользовательские файлы,
не отправляет данные, не использует упаковщики/обфускаторы.

## 2. Что сделано в коде (часть B задания)

1. **Полные сведения о файле** (`src/Monolith/Monolith.csproj`): Company = `MONOLITH`, Product, Copyright, FileDescription
   (`MONOLITH - Windows optimizer / оптимизатор Windows`), Comments (описание на английском и русском), FileVersion/ProductVersion
   из единственного `<Version>`; убрана добавка хеша коммита в версию продукта. Проверено на собранном exe:
   `MONOLITH 1.0.0.0 / 1.0.0, © 2026 MONOLITH`.
2. **Манифест** (`app.manifest`, уже был, проверено, что он внутри exe): `asInvoker` (запуск без UAC; права программа запрашивает сама
   и только когда нужны), `supportedOS` Windows 10/11, `PerMonitorV2` DPI, `longPathAware`. Иконка `Assets/monolith.ico` вшита
   (32×32 читается из exe).
3. **Параметры публикации**, замеры на этом ПК (сборка `dotnet publish -c Release -r win-x64 --self-contained`):

   | Вариант | Размер exe | Комментарий |
   |---|---|---|
   | было: сжатие вкл., ReadyToRun выкл. | **67,5 МБ** | |
   | сжатие выкл., R2R выкл. | 156,4 МБ | не годится: > 120 МБ |
   | сжатие выкл., R2R вкл. | 222,0 МБ | не годится |
   | **стало: сжатие вкл., R2R вкл.** | **87,9 МБ** | запуск (прогретый) ≈ на секунду быстрее, `--selftest` на этом exe: код 0 (ru и en) |

   Вывод: отказаться от сжатия нельзя без роста файла в 2,3 раза (порог в задании ~120 МБ), поэтому сжатие оставлено, а
   ReadyToRun включён (меньше JIT при старте, обычная штатная возможность .NET). `IncludeAllContentForSelfExtract = false`
   явно: на диск распаковываются только несколько нативных библиотек WPF, управляемый код выполняется из памяти.
   Единственный способ полностью избавиться от «упаковки» и распаковки — не-однофайловая публикация (папка с файлами) или
   установщик; для обычного пользователя «один exe без установки» важнее, это решение владельца.
4. **Прозрачность поведения** (пункт c): код не менялся там, где это сломало бы безопасность/откат. Закодированные
   PowerShell-команды уже пишутся в журнал читаемо (`ProcessRunner`, `ChangeSession`, `ChangeJournal` при откате), их список
   ограничен утилитами `System32`; список в разделе 1 — честное объяснение для письма в антивирус.

## 3. Чек-лист владельца (по убыванию пользы)

1. **Подписать код (Authenticode).** Самое сильное средство против SmartScreen и эвристик.
   - Сейчас: `tools\signing-cert.ps1` создаёт *самоподписанный* сертификат **только для вашего ПК** (на чужих ПК он не доверенный,
     SmartScreen это не убирает; см. `docs/signing.md`).
   - Для всех нужен сертификат от удостоверяющего центра (цены ориентировочные, год):
     - **Azure Trusted Signing / Artifact Signing** — дешёвый вариант (порядка 10 $/мес), сертификат на имя организации/физлица
       после проверки личности; подпись сразу доверенная для SmartScreen (доступность по странам и тип заявителя проверяйте на момент подачи).
     - **OV-сертификат** (Sectigo, DigiCert, SSL.com): ~70–250 $/год; репутация SmartScreen копится постепенно.
     - **EV-сертификат**: ~250–500 $/год + аппаратный токен; даёт мгновенную репутацию, но дороже и строже по документам.
     - Бесплатно и без юрлица: **SignPath Foundation** (только для открытого кода) — у MONOLITH репозиторий закрыт, не подходит.
   - После получения: `tools\sign.ps1` / `tools\publish.ps1` подписывают автоматически; самообновление дальше **требует** того же издателя
     у новой версии (код уже это умеет), поэтому менять издателя нужно осознанно.
2. **Отправить exe в Microsoft Defender как ложное срабатывание:**
   <https://www.microsoft.com/en-us/wdsi/filesubmission> → «Software developer» → загрузить `MONOLITH.exe`, указать «ложное срабатывание
   (incorrectly detected as malware/PUA)», адрес сайта (страница релизов), описание (раздел 1 этого файла). Повторять для каждой
   новой версии, если Defender снова ругается. Ответ приходит в течение нескольких дней.
3. **Белые списки других антивирусов** (форма «false positive»/«whitelist», обычно бесплатно): Kaspersky (opentip.kaspersky.com →
   «ложное срабатывание» / Kaspersky Whitelisting), ESET (support.eset.com → «Submit a sample»), Avast/AVG (avast.com/false-positive-file-form),
   Bitdefender, Dr.Web (vms.drweb.ru/sendvirus — «ложное срабатывание»), Malwarebytes (forums → «False positives»), Norton/Symantec
   (submit.norton.com). Проверить файл заранее на virustotal.com — это покажет, кто именно ругается; ссылку на отчёт приложите к
   заявкам. Не заливайте туда секреты: файл общедоступный.
4. **Доверенные каналы распространения:** пакет в **winget** (`microsoft/winget-pkgs`, манифест с `InstallerSha256` и ссылкой на релиз; Microsoft
   сама проверяет файлы — это сильный сигнал репутации) и/или **Microsoft Store** (MSIX, подпись ставит Store; разовая регистрация
   разработчика ~19 $ для физлица). Пока они не оформлены, прямую ссылку на `…/releases/download/…/MONOLITH.exe` давайте вместе с
   SHA-256 из `MONOLITH.exe.sha256`.
5. **Репутация растёт со скачиваниями.** SmartScreen учитывает число скачиваний *одного и того же* файла и возраст; поэтому
   не выпускайте новые версии чаще, чем нужно, и не меняйте имя файла (`MONOLITH.exe`) и издателя. Подписанные версии наследуют
   репутацию сертификата, а не файла.
6. Мелочи, которые помогают: стабильный сайт/страница релизов с описанием; в описании релиза — честно «что делает программа и почему
   её может ругать антивирус» (можно скопировать раздел 1); не упаковывать exe архиватором с паролем (антивирусы такие архивы не
   проверяют и ругаются сильнее) — выкладывать сам `MONOLITH.exe`.

## 4. Что отвечать пользователю, которого остановил SmartScreen

«Подробнее → Выполнить в любом случае» (файл не подписан, поэтому Windows спрашивает). Сверьте хеш: `certutil -hashfile MONOLITH.exe SHA256`
должен совпасть со строкой в `MONOLITH.exe.sha256` со страницы релиза. Если антивирус удалил файл — добавьте папку в исключения
или скачайте снова после того, как заявка в антивирус будет одобрена.
