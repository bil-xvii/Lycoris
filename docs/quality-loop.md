# Цикл доводки Lycoris до идеала (с 03.11.2026)

Руководит Claude; исполнители — оркестр (облачный Codex при наличии квоты, иначе локальная Qwen3.6 через Qwen Code,
по 2 варианта с отбором тестами). Правило для всех: сначала изучить код и документацию, потом делать.
Каждое изменение: полная проверка ветки (сборка 0 предупреждений, все тесты, самопроверка ru/en, gitleaks) →
просмотр diff и снимков Claude → слияние → CI → выпуск. Ничего не ломает систему: любые изменения через ChangeSession
(журнал + откат), только с подтверждением, без отключения защиты Windows.

## Один круг (повторяется, пока круг не найдёт ни одного дефекта)
1. **Интерфейс.** Снимки всех страниц: ru/en × 1380×880 и 1120×720 × Простой/Эксперт. Ищем обрезку, наложения,
   непереведённое, больше одной главной кнопки, мелкий/бледный текст, пустые блоки без пояснения.
2. **Краш-тесты.** `tools/crash-test.ps1` (8 файлов × 7 видов порчи); жёсткие сценарии самопроверкой: папка только для
   чтения, занятые файлы, нет места; стресс: 10 запусков подряд, два экземпляра, закрытие во время операции.
3. **Код.** Разбор всего, что изменилось с прошлого выпуска: потоки, необработанные исключения, утечки подписок/таймеров,
   локализация, semgrep, gitleaks.
4. **Производительность.** `tools/perf-measure.ps1`: время до первого кадра, простой ЦП, память; без регрессий.
5. **Функции.** Сверка с дорожной картой (docs/product-roadmap.md) и с тем, что дают другие оптимизаторы
   (WinUtil, Sophia Script, O&O ShutUp10++): чего не хватает пользователю — в очередь; что опасно — в «Не делаем».
6. **Оценка ПК.** Каждый пункт оценки должен иметь понятную кнопку исправления или честное «решаете вы» с кнопкой.
7. **Выпуск** после зелёной проверки; запись итогов круга ниже.
